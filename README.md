## 设计原则
- **真实边界**：全部项目为课程设计、结课作业与个人练习，明确标注项目来源与适用场景。
- **可复现**：仓库保存完整源代码，配套运行文档、配置说明随项目维护。
- **持续迭代**：部分项目与作品集仍处于更新完善阶段。
