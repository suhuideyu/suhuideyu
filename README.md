## 设计原则
- **本地优先**：个人资料、文档素材与离线包默认不上传。
- **真实边界**：对外部数据、系统估算与本地兜底明确标注。
- **人工确认**：涉及提交、修改、删除和敏感填写时保留用户最终决定权。
